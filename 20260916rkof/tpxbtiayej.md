# 【科普】宝宝缺锌有哪些危害你都知道吗？

> 更新时间：2026-09-16 (UTC+8)

锌：

     是一种微量元素，在人体内参与上百种酶的组成，一旦缺乏，会影响这些酶的活性，会造成儿童出现食欲不佳，异食癖，免疫力低下，生长发育受阻等。

锌有哪些生理功能？

      1、锌在人体内参与200多种酶的组成，参与人体组织细胞呼吸、能量代谢、抗氧化等作用。

      人体内重要的含锌的酶有9种，它们在组织呼吸以及蛋白质、脂肪、糖和核酸等的代谢中有重要作用。

      2、促进机体的生长发育和组织再生。

      锌对于蛋白质和核酸的合成以及对细胞的生长、分裂和分化的各个过程都是必需的。

      因此,锌对于正处于生长发育旺盛期的婴儿、儿童和青少年是非常重要的营养素。

     3、促进食欲。

当人缺锌时,出现食欲缺乏，食欲显著减退.这都证明锌在维持正常食欲中的作用。

     4、锌缺乏对味觉系统有不良的影响，可导致味觉迟钝。

锌可能通过参加构成一种含锌蛋白-唾液蛋白对味觉及食欲起促进作用。

     5、锌可保护皮肤健康。

     人可因缺锌而影响皮肤健康,出现皮肤粗糙、干燥等现象，在组织学上可见上皮角化和食道的类角化。

     6、锌参加免疫功能过程。

     锌在参加包括免疫反应细胞在内的细胞复制中起着重要作用。

     机体缺锌可削弱免疫机制,降低抵抗力,使机体易受细菌感染.。

     生长发育期的儿童对锌的需求量增大，容易导致锌供给不足。

   

     锌是人体必需微量元素之一。

人体的正常生理功能离不开酶的参与，而有大约100种酶需要锌的存在才会具有正常活性。此外，锌还与伤口愈合、体内蛋白质合成、细胞正常分裂等生命活动有关。

     锌对于健康不可或缺，如果锌缺乏，的确可能导致孩子的免疫力下降，从而容易生病。

     人体对锌的需求有一个合理范围，缺乏的时候免疫力下降，把锌补充到合理范围，会恢复正常免疫能力，而且摄入过多还会有害健康，短时间内服下大量的锌，会导致恶心、呕吐、腹痛、腹泻等等。

     而长期锌过量，则会影响铁和铜等其他微量元素的功能，反而会降低免疫力。

     锌的主要生理功能就是促进生长发育，被誉为"生命之花"。

     缺锌会给儿童带来一系列的身体不适，看看自己的孩子是否缺锌。

以下几种表现，只要孩子符合三种，就可视为缺锌：

     1、食欲减退：挑食、厌食、拒食，食量减少，孩子没有饥饿感不主动进食；     2、乱吃奇怪的东西：如咬指甲、衣物、啃玩具、硬物、吃头发、纸屑、生米、墙灰、泥土、沙石等；     3、生长发育缓慢：身高比同龄组的低3—6厘米，体重轻2—3公斤；     4、免疫力低下：经常感冒发烧，反复呼吸道感染，如扁桃体炎、支气管炎、肺炎、出虚汗、睡觉盗汗等；     5、指甲出现白斑，手指长倒刺，地图舌（舌头表面有不规则红白相间图形）；     6、缺乏自控力：多动、反应慢、注意力不集中、学习能力差；     7、视力问题：视力下降，容易导致夜视困难、近视、远视、散光等；     8、皮肤损害：出现外伤时，伤口不容易愈合（非血糖原因），易患皮炎、顽固性湿疹；

     9、青春期性发育迟缓：如男性睾丸与阴茎过小，睾丸酮含量低，性功能低下；女性乳房发育及月经来潮均迟缓；     10、口腔溃疡反复发作。

     如果有自测表中的状况，那就要注意了，宝宝有可能是缺锌。

最好到医院进行微量元素的检测。
