# 【美好孕育】“破水”还是“漏尿”？几招就可辨清楚！

> 更新时间：2026-09-17 (UTC+8)

胎宝宝出生前，是生活在羊水之中的，而羊水是由胎膜包裹着的。如果胎膜发生破裂，羊水就会从中流出，临床上称之为“破膜”，也就是我们俗称的“破水”。

孕妇的分娩不是在突然之间发生的，一般都会有些信号来提醒的。像我们常见的分娩信号就有规律宫缩、破水和见红。

但是很多孕妇破水和漏尿傻傻分不清，有时候已经破水了，孕妇还以为是漏尿，导致没有及时去医院。那孕晚期要如何区分破水和漏尿呢？

**什么是羊水？**

羊水是胎儿附属物之一，是一种充满在羊膜腔内的液体。主要来源于母体血清的透析液、胎儿尿液以及胎肺，主要靠胎膜、胎儿吞咽以及脐带吸收，正常妊娠时羊水的产生和吸收处于动态平衡中，起到保护胎儿和母体的重要作用。

**羊水量的正常范围**

在孕周20周时羊水的量平均是500ml，到了孕28周左右，会增加到700ml，在孕32~36周时最多，为1000~1500ml，其后又逐渐减少。因此临床上以300~2000ml为羊水的正常范围。

羊水过多或过少都会对孕妈和宝宝产生各种影响，所以当孕妈出现羊水过多或过少的情况时一定要及时到医院与医生沟通，寻求最佳的治疗方案。

**如何分辨到底是“破水”还是****“漏尿”？**

**请大家记住这四点！**

**看一看**

**羊水：**羊水一般都是无色清澈的，有些孕妇的羊水中可能会掺杂一些白色的絮状物，这是胎儿脱落的胎脂、皮肤脱落细胞等。

**尿液：**尿液通常是有颜色的，基本上是淡黄色。

**闻一闻**

**羊水：**羊水只是比水要轻微的黏稠一些，通常都是没有气味的。

**尿液：**我们都知道，尿液会有一股氨臭味，比较难闻。

**测一测**

有些孕妇比较心细，到了孕晚期就会准备一些测试酸碱度的PH试纸，以此来判断是破水还是漏尿。尿液和私处的分泌物是呈酸性或者是中性，用试纸测试之后，颜色不会发生变化。而羊水是呈碱性，用试纸测试后，会变成深绿色或者是蓝色。

**可控性**

**羊水：**经历过破水的女性应该知道，破水时的羊水是不受控制地往外流。一旦破水，羊水就会持续不断地流出。哪怕你坐着不动，还是会有液体流出。刚开始是一下出很多，接下来就是“细水长流”式的往外流。

**漏尿：**这种情况，一般是“压力性”的，常常在孕妇咳嗽、打喷嚏、大笑的时候会漏出。但是尿液是可以控制的，在你刻意“憋住”的时候，就不会有尿液排出。

如果孕妈妈一旦发生破水，不管是否到预产期，有没有子宫收缩，先不要慌张，应立即头低臀高位的平卧，并且以头低臀高的姿势送往医院就诊。
