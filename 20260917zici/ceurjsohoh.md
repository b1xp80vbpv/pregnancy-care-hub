# 市一医院党委召开党史学习教育专题民主生活会

> 更新时间：2026-09-17 (UTC+8)

近日，杭州市第一人民医院党委领导班子召开党史学习教育专题民主生活会，会议以“大力弘扬伟大建党精神，坚持和发展党的百年奋斗历史经验，坚定历史自信，践行时代使命，厚植为民情怀，勇于担当作为，团结带领人民群众走好新的赶考之路”为主题，对照党史学习教育要求，结合思想和工作实际，深刻进行自我剖析检查，严肃认真开展批评和自我批评。

市一医院党委书记黄进宇主持会议。市卫健委党委委员、二级巡视员施长友，组织人事处副处长徐旻到会指导。医院党委班子成员参加会议。非中共党员院领导班子成员领导列席。
//

医院党委对开好此次专题民主生活会高度重视，会前认真研究制定工作方案，聚焦主题学习研讨，广泛征求意见，开展谈心谈话，深刻进行对照检查，认真撰写检视剖析材料，扎实做好各环节工作，为开好民主生活会作了充分准备。会上，黄进宇首先通报了2020年度民主生活会查摆问题整改落实情况和本次专题民主生活会准备情况，代表医院党委班子作对照检查，并带头作个人对照检查，紧密联系工作实际深刻剖析问题根源，明确下一步努力方向，有针对性地提出具体整改措施。随后党委班子成员逐一进行个人对照检查发言，并逐人开展了严肃认真的批评和自我批评。大家在发言中紧扣会议主题，查摆严格，意见坦诚，认真检视剖析，明确整改措施，达到了统一思想、深化共识、增进团结、凝聚力量的目的。施长友在总结讲话中就做好医院下一步工作提出四点要求：一是坚持把政治建设摆在首位，在忠诚拥护“两个确立”、坚决做到“两个维护”上展现头雁风采、贡献卫健力量；二是坚持把理论武装抓在经常，在学深悟透笃行伟大思想上展现头雁风采、贡献卫健力量；三是坚持把使命责任扛在肩上，在新的赶考路上展现头雁风采、贡献卫健力量；四是坚持把自我革命要求落到实处，在全面从严治党推进纵深上展现头雁风采、贡献卫健力量。
